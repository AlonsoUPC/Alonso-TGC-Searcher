# 🎴 Alonso's Night Searcher

App web para coleccionar cartas Pokémon TCG. Busca cartas con precios reales
(convertidos a soles), arma tu colección, organiza regalos, y de noche: abre
sobres full-random, compara cartas, llena tu binder 3×3 y revisa tu progreso.

## Funciones
- 🔍 Búsqueda en vivo (TCGdex) con filtros por época, rareza, tipo y clase
- 💰 Presupuestador con precios reales de TCGplayer/Cardmarket → soles
- 🎁 Organizador de regalos por persona + checklist de protección
- 🎴 Abrir sobres al azar con rarezas ponderadas + caja ×36
- 📔 Binder 3×3 con acciones (guardar / regalar / quitar)
- 📊 Progreso por set + wishlist
- 🎮 Datos de combate del Pokémon (sprite animado, stats, Pokédex) vía PokéAPI
- ☀️🌙 Tema día (amanecer) / noche (anochecer)

## Cómo usar
Abre `coleccion.html` en tu navegador. Funciona 100% en el navegador,
sin instalar nada. Los datos se guardan localmente en tu equipo.

## Créditos
- Datos e imágenes de cartas: TCGdex API (https://tcgdex.dev)
- Precios: TCGplayer (USD) y Cardmarket (EUR)
- Datos de Pokémon: PokéAPI (https://pokeapi.co)
- Idea y colección: Alonso
- Programado con la ayuda de Dia 🤖
